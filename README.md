## 🌐 Como Hospedar Gratuitamente no seu GitHub (GitHub Pages)

### Passo a Passo no Navegador (Mais Rápido):

1. **Crie um repositório no GitHub:**
   - Acesse [github.com/new](https://github.com/new)
   - Nome do repositório: `portfolio` (ou `meu-portfolio`)
   - Deixe como **Public**
   - Não marque "Add a README file"
   - Clique em **Create repository**

2. **Faça o upload dos arquivos:**
   - Na tela do repositório, clique em **"uploading an existing file"**
   - Arraste todos os 5 arquivos desta pasta:
     - `index.html`
     - `foto-perfil.jpg`
     - `style.css`
     - `script.js`
     - `README.md`
   - Clique em **Commit changes**

3. **Ative o GitHub Pages:**
   - Vá na aba **Settings** do repositório
   - No menu esquerdo, clique em **Pages**
   - Em **Branch**, selecione `main` e a pasta `/ (root)`
   - Clique em **Save**
   - Em cerca de 1 a 2 minutos seu portfólio estará online no link fornecido pelo GitHub!
